## Diary

## How it works

Talk to bard in a Claude Code session in this repo. Tell it what happened — it writes it down.
Open a project when a thread is worth a work, define its voice, shape the beats, and it drafts.

Rules live in zeroth, not here. Nothing in this repository is published by the AI.
